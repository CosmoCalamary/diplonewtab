# 🚗 Авто

Полезные ресурсы для автомобилистов.

## Основные сервисы

### Продажа и покупка авто

{% list tabs %}

- Авто.ру

  **[Авто.ру](https://auto.ru/)**
  
  Крупнейший российский сайт объявлений о продаже автомобилей.

- Drom.ru

  **[Drom.ru](https://www.drom.ru/)**
  
  Автомобильный портал с объявлениями и форумами.

- Авито Авто

  **[Авито Авто](https://www.avito.ru/rossiya/avtomobili)**
  
  Раздел автомобилей на Авито.

{% endlist %}

### Проверка авто

{% cut "🔍 Проверка истории автомобиля" %}

- **[Автокод](https://avtocod.ru/)** — Полная история автомобиля по VIN или госномеру
- **[Автотека](https://autoteka.ru/)** — Проверка истории авто от Авито
- **[Carfax](https://www.carfax.com/)** — Международная база данных истории авто

{% endcut %}

### Запчасти

{% cut "🔧 Поиск запчастей" %}

- **[Exist.ru](https://exist.ru/)** — Каталог автозапчастей
- **[Emex](https://www.emex.ru/)** — Заказ автозапчастей онлайн
- **[Автодок](https://autodoc.ru/)** — Интернет-магазин автозапчастей

{% endcut %}
