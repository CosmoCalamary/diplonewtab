## Перевод текста {#perevod-teksta}

{% list tabs %}

- Google Translate

  **[Google Translate](https://translate.google.com/)**
  
  Самый популярный онлайн-переводчик. Поддерживает более 100 языков.

- DeepL

  **[DeepL](https://www.deepl.com/translator)**
  
  Лучший переводчик для европейских языков. Более естественные переводы чем у Google.

- Яндекс.Переводчик

  **[Яндекс.Переводчик](https://translate.yandex.ru/)**
  
  Отличный переводчик для русского языка.

{% endlist %}
