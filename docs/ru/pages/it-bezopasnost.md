# 🔒 IT - Безопасность

Ресурсы для обеспечения информационной безопасности.

## Основные инструменты

### Менеджеры паролей

{% list tabs %}

- Bitwarden

  **[Bitwarden](https://bitwarden.com/)**
  
  Открытый и безопасный менеджер паролей.

- KeePass

  **[KeePass](https://keepass.info/)**
  
  Бесплатный оффлайн менеджер паролей.

- 1Password

  **[1Password](https://1password.com/)**
  
  Профессиональный менеджер паролей для команд.

{% endlist %}

### VPN сервисы

{% cut "🔐 Безопасное соединение" %}

- **[ProtonVPN](https://protonvpn.com/)** — Бесплатный VPN от создателей ProtonMail
- **[Windscribe](https://windscribe.com/)** — VPN с бесплатным тарифом
- **[Mullvad](https://mullvad.net/)** — Анонимный VPN сервис

{% endcut %}

### Проверка безопасности

{% cut "🛡️ Анализ угроз" %}

- **[VirusTotal](https://www.virustotal.com/)** — Проверка файлов и URL на вирусы
- **[Have I Been Pwned](https://haveibeenpwned.com/)** — Проверка утечек паролей
- **[SSL Labs](https://www.ssllabs.com/ssltest/)** — Тест SSL/TLS конфигурации

{% endcut %}
